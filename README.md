# WP ContentKit

**Smart Tools for Better Content.**

WP ContentKit adalah plugin WordPress ultra-ringan yang menggabungkan **Smart Table of Contents (TOC) berbasis Server-Side Rendering (SSR)** untuk Elementor dengan generator **Inline Content Box portabel** untuk Classic Editor.

---

## Fitur Utama

### 1. Smart Table of Contents (Elementor Add-on)
- **100% Server-Side Rendered (SSR)**: Bebas loading spinner & kebal terhadap JS delay/defer (Perfmatters, FlyingPress, WP Rocket, LiteSpeed Cache, Cloudflare).
- **Heading Hierarchy Validator**: Mendeteksi loncatan struktur heading (H2–H6) dan memberikan saran SEO ramah pemula langsung di panel Elementor.
- **Stable Anchor IDs**: Slug ID unik otomatis tanpa tabrakan nama heading duplikat.
- **Smooth Scroll & Sticky Offset**: Navigasi mulus dengan kompensasi jarak header sticky.

### 2. Inline Content Box (Classic Editor Utility)
- **Zero-Dependency Styling**: Menghasilkan HTML dengan inline CSS murni—dapat dicopy-paste ke platform lain tanpa kehilangan tampilan.
- **7 Template Siap Pakai**:
  1. Poin Penting (Important Points)
  2. Author Box
  3. Reviewed By / Ditinjau Oleh (E-E-A-T friendly)
  4. Related Content / Baca Juga
  5. Note / Catatan
  6. Warning / Peringatan
  7. Simple Info Box
- **Custom Box Generator**: Kustomisasi bebas warna, border, radius sudut, dan padding.
- **Live Preview Modal**: Pratinjau langsung sebelum disematkan ke editor.

### 3. GitHub Auto-Update
- Terintegrasi langsung dengan GitHub Releases repository `muzzafah-stack/WP-ContentKit` untuk update otomatis 1-klik di dashboard WordPress.

---

## Instalasi

1. Download file zip dari [GitHub Releases](https://github.com/muzzafah-stack/WP-ContentKit/releases).
2. Di dashboard WordPress, buka **Plugins > Add New > Upload Plugin**.
3. Upload file zip dan klik **Activate Plugin**.
4. Kelola preferensi melalui menu **WP ContentKit** di sidebar admin.
